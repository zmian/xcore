| Symbol | Owner | Default |
| --- | --- | --- |
| `defaultEncodeAsString` | `CodingFormatStyleDefaults` | `false` |

`DecimalCodingFormatStyle.defaultEncodeAsString` and `DoubleCodingFormatStyle.defaultEncodeAsString` forward to the same storage.
